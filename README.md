Most of the contribution graph is private production work across **14 repositories** in the [Carousel-Shop-AI](https://github.com/Carousel-Shop-AI) organization:

- three Spring Boot microservices on Cloud Run
- 12+ Python Cloud Functions in a Pub/Sub event mesh
- a React web app and a native SwiftUI iOS app (live on the App Store)
- Terraform infrastructure, CI/CD, and schema-migration pipelines for Firestore and BigQuery
- internal Claude Code skills and plugins, including a guardrails plugin for AI coding agents

All of it is built agent-first with Claude Code under full engineering governance: plans reviewed before any code is written, every diff reviewed before it merges, and CI/CD promotion from dev to prod.

## Public work

## How I think about AI-native delivery

AI has made writing code the fast part. Review, judgment, and validation are the new bottleneck, so that is where I put the guardrails, and where I help engineering teams build the habits to trust what agents produce.
